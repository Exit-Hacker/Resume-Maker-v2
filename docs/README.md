# 📄 Japanese Resume Maker

A simple web-based Japanese resume (履歴書) maker.

Create a Japanese-style resume directly in your browser and prepare it for printing/PDF.

## ✨ Features

- 👤 Personal information
- 📞 Contact information
- 🏠 Address
- 🎓 Education history (学歴)
- 💼 Work history (職歴)
- 📷 Profile photo
- 📅 Resume date
- 🖨️ A4 resume preview
- 📄 PDF / Print support
- 💾 Save and load resume data
- 📱 Responsive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub Pages
